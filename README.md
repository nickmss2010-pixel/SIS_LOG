# NDN Transportes

Sistema de gerenciamento de pacotes desenvolvido para auxiliar na organização, separação, conferência, embalagem e envio de mercadorias.

## Objetivo

O projeto busca reduzir problemas relacionados à perda e à má organização de pacotes durante os processos de transporte, proporcionando uma aplicação simples, organizada e intuitiva.

## Funcionalidades

* Cadastro de pacotes
* Organização de pacotes
* Separação de pacotes
* Confirmação de pacotes
* Embalagem de pacotes
* Organização por rota
* Consulta de pacotes
* Acompanhamento de pacotes
* Envio de pacotes
* Gerenciamento de usuários

## Usuários

A aplicação é destinada principalmente a:

* Separadores de mercadorias
* Conferentes
* Motoristas
* Representantes da empresa
